# 离线图鉴与提示词

首次打开工作台就能在提示词中输入中英文查找标签，也可以从画师或角色选择器中挑选条目。随附图鉴可离线搜索。切换到「官方」联想时，工作台会向 NovelAI 查询当前标签。

| 随附内容 | 数量 | 可尝试的搜索 |
| --- | ---: | --- |
| 标签联想总数（含各类别） | 336,155 | 蓝发、depth of field、Hatsune Miku |
| 常规标签（已包含在联想总数中） | 53,664 | rain、soft lighting |
| 画师图鉴 | 15,879 | Fuzichoco |
| 角色图鉴 | 34,301 | 初音未来、Hatsune Miku |

本地联想使用 ffdkj 的中英文对照表。输入 `hair` 或「蓝发」时，优先显示匹配的常规标签；精确命中的名称优先，`artist:` 和 `character:` 可限定类别。候选旁标有常规、画师、作品、角色或元数据，每次最多显示 20 项。同组优先显示使用次数较高的词。要复现内置词表，在源码目录运行 `python scripts/build-ffdkj-tags.py`。[本期上游快照](https://github.com/ffdkj/ffdkj-Danbooru_Tag-Chinese-English-Translation-Table/tree/15f5f4b50428226649d371cbf7faff8ddaacdb24) · [MIT 许可](../public/catalog-data/ffdkj-LICENSE.txt)

其中 26,620 个图鉴角色有外貌记录。勾选「附带外貌标签」，选中的角色就会连同发型、服装等标签一起进入多角色栏。

**想知道一个标签常和什么搭配？** 在候选里选中 `rain`，或在编辑框点一下已经写好的 `rain`。在「搭配预测」中选择 `umbrella`，它就会插在 `rain` 后面。「样本同现 8,407」表示在这份公开样本中有 8,407 张图同时带有这两个标签。排序同时考虑共同出现次数和两个词各自的常见程度。索引覆盖 30,234 个标签，每个保留至多 48 个搭配。[共现数据快照](https://huggingface.co/datasets/newtextdoc1111/danbooru-tag-csv/tree/fdf2772213f13d46bff60fc5ebd876e1a811a053)

正向和负向栏都只按公开样本的同现记录推荐，跳过当前栏已写过的标签，每次最多显示 20 个。如果该标签缺少样本，或能推荐的搭配都已填入，候选框会收起。导入词库后，只显示当前词库收录的搭配。

两种下载包都内置完整文字索引和 24 张图鉴封面。打开图鉴时优先用本地封面，其他条目在进入视野时从 AnimaDex 获取缩略图。离线时仍然可以检索、查看外貌和选择条目，缺图的卡片会显示首字。

首次使用词块库时有六个可编辑的起步词块，分别为柔和侧光、空气透视、清透色彩、雨后街角、天台蓝调和旅行手账。负面提示的轻度、重度和主体选项使用 Folio 编写的提示词。生成设置保留各模型支持的预设键和画幅尺寸。

## 切换到另一份图鉴

准备一份自己有权使用的 Folio 格式索引目录。在项目根目录执行下列命令，将引号中的路径改为实际位置。

```sh
node scripts/import-catalog.mjs "<你的目录>/public/catalog-data"
```

启动工作台后，在地址末尾加上 `?catalog=local` 打开一次，例如 `http://127.0.0.1:4389/?catalog=local`。浏览器会记住此次选择，以后可直接打开首页。用 `?catalog=sample` 切回内置图鉴。其他浏览器或端口需要单独选择。

导入器读取 `tags.json`、`artist.json`、`character.json`，以及可选的 `character-details.json` 和 `related-tags.json`。它会复制索引中引用的本地 PNG、JPEG、WebP、AVIF 封面，去掉远程预览地址。缺少本地封面的条目显示首字。源目录保持原样。

导入成功后，新版本在 `public/catalog-data/local/` 下生效，刷新已打开的页面即可使用。原有页面仍可读取之前的版本。这个目录已被 Git 忽略，制作公开压缩包时也应排除它。导入失败时，上次成功的版本仍可用。

## 索引格式

所有索引均为 UTF-8 JSON。主键使用小写英文和空格以便匹配。短行可以省略末尾的字段。

- `tags.json` 的每行依次为主键、中文名、类别、使用次数、竖线分隔的别名。常规为 0，画师为 1，版权或作品为 3，角色为 4，元数据为 5。
- `artist.json` 和 `character.json` 的每行依次为主键、显示名、实际插入的提示词、中文名、作品名、使用次数、远程预览字段、本地封面路径、竖线分隔的别名、中文作品名。封面路径从 `covers/` 开始。
- `character-details.json` 使用角色主键映射到外貌提示词数组。可参照随附的角色记录编写。
- `related-tags.json` 是旧版图鉴的关联词表，导入器可保留此文件。搭配预测的数据来自 `cooccurrence/` 中按标签分片的公开样本统计。
